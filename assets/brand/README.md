# DriveMatch Brand Assets

Pacote oficial de assets da marca DriveMatch.

## Estrutura

### logo/

Logos principais e compactas, disponíveis para fundos claros e escuros.

### symbol/

Símbolo da marca em diferentes resoluções.

### favicon/

Favicons para aplicações web.

### pwa/

Ícones destinados a Progressive Web Apps, incluindo versões maskable e Apple Touch Icon.

## Cores principais

- Azul principal: #2563EB
- Azul escuro: #172554
- Fundo claro: #F8FAFC

## Observação

Os arquivos foram derivados dos assets aprovados da marca.
Nenhum elemento gráfico foi redesenhado por IA.
As versões redimensionadas mantêm a proporção original e não sofrem cortes.
